# Week 2 Reflection Journal

## What did I learn this week?

This week I continued developing my JavaScript skills and learned more about frontend and backend development.

I practiced working with arrays, objects, functions, and different JavaScript programming tasks. I also worked with Node.js and backend exercises, including working with APIs and processing data.

On the frontend side, I practiced React and learned more about components and how different parts of a frontend application can work together.

I also continued using Git and GitHub to organize and submit my work. I practiced adding, committing, and pushing my exercises to GitHub.

## What was challenging?

One of the challenging parts was understanding how different JavaScript concepts work together. Some individual concepts were easy to understand, but using them together to solve a complete problem required more practice.

Working with APIs was also challenging because I needed to understand how data is received, processed, and used by an application.

I also had a Git problem where my `linux-exercises` folder appeared on GitHub with an arrow. I learned that this happened because Git was treating the folder as a separate repository. I learned how to identify the problem and convert it into a normal folder.

React was also challenging because I needed to understand how components are structured and how information is passed between them.

## What did I enjoy?

I enjoyed the practical programming exercises because they helped me understand the concepts better than only reading theory.

I particularly enjoyed working with APIs and React because I could see how frontend and backend technologies are used to build applications.

I also enjoyed using GitHub to store my work and see my progress.

# Week 1 Reflection Journal

## What did I learn this week?

This week I learned the basic tools and workflow used in web development. I practiced using the Linux terminal and learned how to navigate directories, create files and folders, and work with files using command-line commands.

I also learned the basics of Git and GitHub. I practiced checking the status of a repository, adding files, committing changes, and pushing my work to GitHub. This helped me understand how version control is used to track programming work.

I also practiced JavaScript and Node.js exercises. I worked with functions, arrays, objects, and basic JavaScript concepts.

## What was challenging?

Using the terminal was challenging at first because I was not familiar with all the commands. I also had to understand the differences between PowerShell and Linux/Git Bash commands.

Git and GitHub were another challenging part. I had problems understanding how Git tracks folders and repositories. I learned that a folder containing its own `.git` directory can be treated as a separate repository.

Solving these problems helped me understand Git better and taught me how to check errors instead of just repeating commands.

## What did I enjoy?

I enjoyed the practical exercises because I could immediately see the results of the commands and programs I created.

I especially enjoyed learning Git and GitHub because they are important tools for software development. I also enjoyed practicing JavaScript because it helped me understand programming concepts through practical tasks.

## How did I work with others?

The group activities helped me understand the importance of communication and teamwork. Discussing problems and possible solutions with other students helped me see different approaches to programming tasks.

I learned that working together can make it easier to find mistakes and understand difficult concepts.

## What do I need to improve?

I need to improve my knowledge of Linux commands and Git commands because I sometimes need to check the correct command before continuing.

I also need to improve my JavaScript problem-solving skills and become more comfortable solving exercises independently.

## Overall reflection

Week 1 gave me a useful foundation for the course. I learned how to use the terminal, Git, GitHub, JavaScript, and Node.js.

Some parts were difficult at first, but solving the problems helped me understand the tools better. I feel more confident than I did at the beginning of the week and I want to continue improving my programming and Git skills in the following weeks.

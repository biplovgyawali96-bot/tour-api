## What I learned

This week I learned more about:

* Rendering lists with `map()`
* Destructuring

* REST APIs
* HTTP methods such as GET, POST, PATCH, and DELETE

The Tour API was especially useful because I could see how different parts of a backend application work together. I practiced creating, reading, updating, and deleting tours and also added validation.

## Challenges

One challenge was understanding how the different parts of an Express API connect together. At first, it was difficult to understand the relationship between routes, handlers, and the data library.

Git was also sometimes challenging when working with a partner. I learned that pulling changes, checking the Git status, committing regularly, and communicating with my partner are important when working on the same project.

## How I improved

I improved by completing the tasks step by step and testing my code after each iteration. I also became more comfortable with Git and GitHub and learned how to continue working after pulling changes made by my partner.

Pair programming also helped me understand how a larger project can be divided into smaller tasks and completed together.

## What I need to improve

I still need more practice with JavaScript, React, and Express. I want to become more confident writing code without always checking examples.

I also want to improve my Git skills, especially when collaborating with other developers.

## Overall reflection

Week 3 was challenging but useful. I gained practical experience with both frontend and backend development. I learned more about React, Express, APIs, MVC, middleware, Git, and pair programming.

I feel more confident working with APIs and React than I did before this week. I still have things to improve, but I understand the development process better and feel more comfortable working on projects with a partner.
